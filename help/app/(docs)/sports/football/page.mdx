# Football

Football matches run as 2 halves of 45:00 each on ScoreHub's football template.

## Match structure

- Periods: 2 × HALF
- Clock: counts up from 0:00, no fixed length

## Scoring buttons

- **1** — a goal

## Running the match

Score the match from the goal button above on `/control`. See [Getting started](/getting-started)
for creating the match and finding the control panel link.
