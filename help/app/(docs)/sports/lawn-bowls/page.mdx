# Lawn Bowls

Lawn Bowls matches run over 21 ends on ScoreHub's lawn bowls template.

## Match structure

- Periods: 21 × END
- Clock: counts up from 0:00, no fixed length

## Scoring buttons

- **1, 2, 3, 4** — the number of shots (bowls closest to the jack) won on an end

## Running the match

Score the match from the shot-count buttons above on `/control`. See
[Getting started](/getting-started) for creating the match and finding the control panel link.
