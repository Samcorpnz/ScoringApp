# Hockey

Hockey matches run as 4 quarters of 15:00 each on ScoreHub's hockey template.

## Match structure

- Periods: 4 × QTR
- Clock: 15:00 countdown per quarter
- Timeouts: 1 per team

## Scoring buttons

- **1** — a goal

## Running the match

Score the match from the goal button above on `/control`. See [Getting started](/getting-started)
for creating the match and finding the control panel link.
