# Futsal

Futsal matches run as 2 halves of 20:00 each on ScoreHub's futsal template.

## Match structure

- Periods: 2 × HALF
- Clock: 20:00 countdown per half
- Timeouts: 1 per team

## Scoring buttons

- **1** — a goal

## Running the match

Score the match from the goal button above on `/control`. See [Getting started](/getting-started)
for creating the match and finding the control panel link.
