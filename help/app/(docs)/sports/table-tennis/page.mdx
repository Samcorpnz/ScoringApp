# Table Tennis

Table Tennis matches run as best of 7 games to 11 on ScoreHub's table tennis template.

## Match structure

- Periods: 7 × GAME
- Clock: counts up from 0:00, no fixed length
- Timeouts: 1 per team
- Scores reset each period: each game starts back at 0–0

## Scoring buttons

- **1** — a point

## Running the match

Score the match from the point button above on `/control`. See [Getting started](/getting-started)
for creating the match and finding the control panel link.
