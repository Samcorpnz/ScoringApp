# Floorball

Floorball matches run as 3 periods of 20:00 each on ScoreHub's floorball template.

## Match structure

- Periods: 3 × PERIOD
- Clock: 20:00 countdown per period
- Timeouts: 1 per team

## Scoring buttons

- **1** — a goal

## Running the match

Score the match from the goal button above on `/control`. See [Getting started](/getting-started)
for creating the match and finding the control panel link.
