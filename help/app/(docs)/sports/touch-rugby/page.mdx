# Touch Rugby

Touch Rugby matches run as 2 halves of 40:00 each on ScoreHub's touch rugby template.

## Match structure

- Periods: 2 × HALF
- Clock: 40:00 countdown per half

## Scoring buttons

- **1** — a touchdown

## Running the match

Score the match from the touchdown button above on `/control`. See
[Getting started](/getting-started) for creating the match and finding the control panel link.
