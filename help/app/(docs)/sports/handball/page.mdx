# Handball

Handball matches run as 2 halves of 30:00 each on ScoreHub's handball template.

## Match structure

- Periods: 2 × HALF
- Clock: 30:00 countdown per half
- Timeouts: 3 per team

## Scoring buttons

- **1** — a goal

## Running the match

Score the match from the goal button above on `/control`. See [Getting started](/getting-started)
for creating the match and finding the control panel link.
