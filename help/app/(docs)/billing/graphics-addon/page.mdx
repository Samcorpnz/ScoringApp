# Graphics Operator add-on

**Graphics Operator** adds broadcast-style scene graphics to `/display` — driven live from the
control panel, for productions that want more than a plain scoreboard on stream.

| | Monthly | Annual |
| --- | --- | --- |
| Graphics Operator | $29 | $290 |

It's an add-on, not a plan — it bills on its own subscription, on top of whichever plan you're on.
It requires an active **Pro** or **Venue** plan; it isn't available on Free.

## Buying it

From **Account → Plan & Billing** (Admins only), scroll to the Graphics Operator card, choose
Monthly or Annual, and check out the same way as a plan upgrade. It activates as soon as payment
completes.

## Using it

Once active, `/control/graphics` lets an operator switch what scene is showing, and
`/display/graphics` is the single stable Browser Source URL to drop into OBS/vMix/Wirecast — you
set that URL once and never need to change it again as scenes change. See
[Displaying your score](/displaying-your-score) for how it fits alongside the other display
routes.

## Cancelling the add-on

The add-on cancels independently of your plan — cancelling it doesn't touch your Pro/Venue
subscription. It works the same way as [cancelling a plan](/billing/cancelling): it stays active
until the end of the current billing period.
